# Thesis Publication Figures Directory Structure

This directory stores publication-ready vector PDF figures generated by the RAG benchmark evaluation suite (`rag-evaluator`).

## Directory Layout

- **`./` (Root Figures):**
  - Canonical/active figures directly embedded in `thesis/chapters/05_results.tex` (`\includegraphics{figures/...}`).
  - `latency_breakdown.pdf`: Stacked bar chart decomposing execution latency across all active micro-phases (vector retrieval, semantic re-ranking, context expansion, generation/prefill/stream, routing, caching, and overhead).
  - `cost_breakdown.pdf`: Stacked bar chart decomposing operational expenditures across uncached prompt tokens, context caching read tokens, generation completion tokens, semantic re-ranking, and auxiliary services normalized per 1,000 queries.
  - `pareto_frontier.pdf`: 2D Pareto frontier analyzing cost ($) vs latency (ms) vs Composite Quality.
  - `pareto_frontier_3d.pdf`: 3D empirical Pareto surface.
  - `ragas_metrics_radar.pdf`: Radar/spider chart of RAGAS quality dimensions across configurations.
  - `tradeoff_sensitivity.pdf`: Enterprise trade-off continuum and sensitivity sweep.

- **`canonical/`:**
  - Preserved archive copies of the baseline canonical figures for safe keeping and comparison.

- **`sample_runs/`:**
  - Output figures from sample/quick evaluation runs (e.g., 5 or 10 question subsets).

- **`musique/`:**
  - Output figures from full MuSiQue multi-hop benchmark evaluations.

- **`nordea/`:**
  - Output figures from Nordea enterprise financial domain evaluations.

- **`comparisons/`:**
  - Comparison charts and ablation figures between specific pipeline configurations.

- **`runs/`:**
  - Custom or timestamped run folders (e.g., `runs/run_20260904/`, `runs/exp_hybrid_reranking/`).

## How to Export into Run Folders

Using the `export-thesis` command in `rag-code/rag-evaluator`:

```bash
# Export figures to a subfolder using --subfolder:
poetry run python -m src.cli export-thesis \
  --input runs/sample5 \
  --subfolder sample_runs

# Or specify custom tables and figures directories:
poetry run python -m src.cli export-thesis \
  --input runs/nordea_evaluated.jsonl \
  --tables-dir thesis/tables/nordea \
  --figures-dir thesis/figures/nordea
```
