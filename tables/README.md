# Thesis LaTeX Tables Directory Structure

This directory stores publication-ready LaTeX tables generated by the RAG benchmark evaluation suite (`rag-evaluator`).

## Directory Layout

- **`./` (Root Tables):**
  - Canonical/active tables directly referenced by `thesis/chapters/05_results.tex` (`\input{tables/...}`).
  - `benchmark_summary.tex`: Overall latency, cost, EM, F1, RAGAS scores, and Composite Q across configurations.
  - `hop_breakdown.tex`: Reasoning complexity breakdown stratified by reasoning hops.
  - `wilcoxon_tests.tex`: Paired Wilcoxon signed-rank test results with Holm-Bonferroni correction.

- **`canonical/`:**
  - Preserved archive copies of the baseline canonical tables for safe keeping and comparison.

- **`sample_runs/`:**
  - Output tables from sample/quick evaluation runs (e.g., 5 or 10 question subsets).

- **`musique/`:**
  - Output tables from full MuSiQue multi-hop benchmark evaluations.

- **`nordea/`:**
  - Output tables from Nordea enterprise financial domain evaluations.

- **`comparisons/`:**
  - Dedicated paired comparison tables and Wilcoxon hypothesis tests between specific configurations.

- **`runs/`:**
  - Custom or timestamped run folders (e.g., `runs/run_20260904/`, `runs/exp_hybrid_reranking/`).

## How to Export into Run Folders

Using the `export-thesis` command in `rag-code/rag-evaluator`:

```bash
# Export using the --subfolder shortcut:
poetry run python -m src.cli export-thesis \
  --input runs/sample5 \
  --subfolder sample_runs

# Export directly to a specific folder:
poetry run python -m src.cli export-thesis \
  --input runs/musique_evaluated.jsonl \
  --tables-dir thesis/tables/musique \
  --figures-dir thesis/figures/musique
```

To export a paired Wilcoxon comparison table:
```bash
poetry run python -m src.cli compare \
  --baseline runs/run_C0_baseline.jsonl \
  --treatment runs/run_C1_M1.jsonl \
  --config-name "Small-to-Big (C1)" \
  --output-latex thesis/tables/comparisons/wilcoxon_C1_vs_C0.tex
```
