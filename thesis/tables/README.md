# Thesis LaTeX Tables Directory Structure

This directory stores publication-ready LaTeX tables generated by the RAG benchmark evaluation suite (`rag-evaluator`).

## Directory Layout

- **`musique/` (Chapter 5: Academic Multi-Hop Benchmark):**
  - Academic multi-hop QA benchmark tables referenced by `thesis/chapters/05_results.tex`.
  - `tab_latency_musique.tex`: Latency profile across configurations ($C_0$--$C_{15}$), detailing TTFT, P50/P95 end-to-end execution, and retrieval/re-ranking breakdown (`\input{tables/musique/tab_latency_musique}`).
  - `tab_cost_musique.tex`: Operational expenditure and token accounting per 1,000 queries, detailing prefill, context cache lookups, and generation costs (`\input{tables/musique/tab_cost_musique}`).
  - `tab_quality_musique.tex`: Quality metrics across configurations, reporting Context Precision, Context Recall, Faithfulness, Answer Relevancy, Composite Quality ($Q$), EM, and F1 (`\input{tables/musique/tab_quality_musique}`).
  - `tab_pareto_musique.tex`: Empirical Pareto frontier configurations balancing latency, cost, and quality (`\input{tables/musique/tab_pareto_musique}`).
  - `benchmark_summary.tex`: High-level summary aggregating latency, cost, and quality across configurations.
  - `hop_breakdown.tex`: Performance stratified by MuSiQue reasoning hops (2, 3, and 4 hops).
  - `wilcoxon_tests.tex`: Consolidated paired Wilcoxon signed-rank tests with Holm-Bonferroni step-down correction against baseline $C_0$.
  - `wilcoxon_rq1_latency.tex`, `wilcoxon_rq1_ttft.tex`, `wilcoxon_rq2_cost.tex`, `wilcoxon_rq3_quality.tex`: Decomposed Wilcoxon test tables stratified by research question.

- **`enterprise_closed/` (Chapter 5: Enterprise Production Closed Corpus):**
  - Enterprise closed-domain benchmark tables referenced by `thesis/chapters/05_results.tex`.
  - `tab_latency_enterprise.tex`: Latency breakdown on the closed enterprise corpus (`\input{tables/enterprise_closed/tab_latency_enterprise}`).
  - `tab_cost_enterprise.tex`: Operational expenditure and context caching savings on the closed enterprise corpus (`\input{tables/enterprise_closed/tab_cost_enterprise}`).
  - `tab_quality_enterprise.tex`: Quality and RAGAS metrics on the closed enterprise corpus (`\input{tables/enterprise_closed/tab_quality_enterprise}`).
  - `tab_pareto_enterprise.tex`: Empirical Pareto frontier configurations for the closed enterprise corpus (`\input{tables/enterprise_closed/tab_pareto_enterprise}`).
  - `benchmark_summary.tex`: High-level aggregated benchmark summary.
  - `hop_breakdown.tex`: Complexity stratification across enterprise query tiers.
  - `wilcoxon_tests.tex`: Consolidated paired Wilcoxon signed-rank tests with Holm-Bonferroni correction vs. baseline $C_0$.
  - `wilcoxon_rq1_latency.tex`, `wilcoxon_rq1_ttft.tex`, `wilcoxon_rq2_cost.tex`, `wilcoxon_rq3_quality.tex`: Decomposed Wilcoxon test tables.

- **`enterprise/` (Appendix C: Raw Unconstrained Enterprise Corpus):**
  - Supplementary tables evaluated against the raw unconstrained corpus referenced by `thesis/chapters/0C_appendix.tex`.
  - `tab_latency_enterprise.tex`: Latency metrics on the unconstrained corpus (`\input{tables/enterprise/tab_latency_enterprise}`).
  - `tab_cost_enterprise.tex`: Cost decomposition on the unconstrained corpus (`\input{tables/enterprise/tab_cost_enterprise}`).
  - `tab_quality_enterprise.tex`: Response quality on the unconstrained corpus (`\input{tables/enterprise/tab_quality_enterprise}`).
  - `tab_pareto_enterprise.tex`: Pareto trade-offs on the unconstrained corpus (`\input{tables/enterprise/tab_pareto_enterprise}`).
  - `benchmark_summary.tex`: Aggregated benchmark summary for the unconstrained corpus.
  - `hop_breakdown.tex`: Query depth breakdown for the unconstrained corpus.
  - `wilcoxon_tests.tex`: Consolidated paired Wilcoxon signed-rank tests.
  - `wilcoxon_rq1_latency.tex`, `wilcoxon_rq1_ttft.tex`, `wilcoxon_rq2_cost.tex`, `wilcoxon_rq3_quality.tex`: Decomposed Wilcoxon test tables.

## How to Export Tables Using `export-thesis`

LaTeX tables and corresponding vector PDF figures are generated using the `export-thesis` CLI command in `rag-code/rag-evaluator`.

### CLI Command Options

- `--input`, `-i`: Directory containing run JSONL files (e.g., `runs/musique_all16/`) or a single evaluated JSONL file.
- `--tables-dir`: Path to the thesis LaTeX tables root (defaults to `thesis/tables` or `../../thesis/tables`).
- `--figures-dir`: Path to the publication figures directory (defaults to `thesis/figures` or `../../thesis/figures`).
- `--subfolder`, `-s`: Target subfolder name (`musique`, `enterprise_closed`, or `enterprise`). Automatically isolates tables and figures.
- `--dataset-name`, `-d`: Explicit dataset name for captions and figure headers (e.g., `MuSiQue`, `Enterprise Closed`, `Enterprise`).
- `--family-scope`: Holm-Bonferroni correction family scope (`metric`, `rq`, `config`, `global`; default: `metric`).

### Export Examples

```bash
# In rag-code/rag-evaluator:

# 1. Export academic multi-hop benchmark tables (Chapter 5):
poetry run python -m src.cli export-thesis \
  --input runs/musique_all16 \
  --tables-dir ../../thesis/tables \
  --figures-dir ../../thesis/figures \
  --subfolder musique \
  --dataset-name "MuSiQue"

# 2. Export enterprise production closed corpus tables (Chapter 5):
poetry run python -m src.cli export-thesis \
  --input runs/enterprise_closed_all16 \
  --tables-dir ../../thesis/tables \
  --figures-dir ../../thesis/figures \
  --subfolder enterprise_closed \
  --dataset-name "Enterprise Closed"

# 3. Export raw unconstrained enterprise corpus tables (Appendix C):
poetry run python -m src.cli export-thesis \
  --input runs/enterprise_all16 \
  --tables-dir ../../thesis/tables \
  --figures-dir ../../thesis/figures \
  --subfolder enterprise \
  --dataset-name "Enterprise"
```

### Paired Wilcoxon Hypothesis Test Exports

Individual paired Wilcoxon comparison tables can also be generated directly using `compare`:

```bash
poetry run python -m src.cli compare \
  --baseline runs/run_C0_baseline.jsonl \
  --treatment runs/run_C1_S2B.jsonl \
  --config-name "Small-to-Big (C1)" \
  --output-latex ../../thesis/tables/musique/wilcoxon_C1_vs_C0.tex
```
